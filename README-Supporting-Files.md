# Exam Result Management System — Supporting Files

This folder contains supporting documentation and conceptual diagrams for the project.

## Files
- `docs/Project-Abstract.md` — short project abstract
- `docs/Project-Report.docx` — editable project report
- `docs/System-Design.pdf` — high-level system design overview
- `diagrams/Use-Case-Overview.png` — role and feature overview
- `diagrams/Flowchart.png` — basic application workflow
- `diagrams/ER-Diagram-Concept.png` — conceptual data relationship diagram

## Upload to GitHub
1. Download and extract this ZIP.
2. Open your existing `Exam-Result-Management-System` GitHub repository.
3. Upload the `docs` and `diagrams` folders, along with this README if you want to replace or update your repository README.
4. Keep your existing `index.html` in the repository root.

## Important note
The diagrams are high-level academic illustrations, not a database schema extracted from a live backend. The current application is a front-end demo using browser localStorage; it does not provide a shared online database. Update the report and diagrams if you later add backend/database features.
